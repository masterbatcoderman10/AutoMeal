## Phase Goal

Close the Phase 04.1 live UAT gap by making grouped reasoning the food-naming authority, removing the extra segment-labeling step from the live UAT path, and validating from an empty DB through repeated real meal uploads.

<objective>
Fix the grouped learning loop so classification only answers food/not-food, segmentation only finds crops/groups, reasoning names foods at useful Indo-Pak specificity, and confirmed reasoning/interview outputs create FoodItems/FoodVisuals for later vector matches.

Purpose: The current UAT is too seeded and implementation-shaped. It uses a separate segment label step before reasoning, starts with unknown seeded candidates, and only proves one sample. Human UAT should start with an empty app DB, upload 3-4 natural meals, confirm/interview when needed, then prove repeated meals use newly learned embeddings.
Output: disabled/non-authoritative labeling in the grouped UAT/live reasoning path, targeted gate fix, empty-DB grouped UAT script/checklist, and repeated-meal evidence that FoodVisual embeddings reduce future interview.
</objective>
