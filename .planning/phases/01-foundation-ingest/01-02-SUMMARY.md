## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] SQLAlchemy 2.0.36 has no exported `TIMESTAMPTZ` symbol**
- **Found during:** Model import verification after Task 9
- **Issue:** `from sqlalchemy.dialects.postgresql import TIMESTAMPTZ` raised `ImportError`; SQLAlchemy 2.0.36 exposes `TIMESTAMP(timezone=True)` for PostgreSQL timestamptz behavior.
- **Fix:** Aliased `TIMESTAMP` as `TIMESTAMPTZ` in model files and migration while keeping every timestamp column as `TIMESTAMPTZ(timezone=True)`.
- **Files modified:** `app/models/meal_log.py`, `app/models/meal_segment.py`, `app/models/food_item.py`, `app/models/food_visual.py`, `app/models/diary_entry.py`, `migrations/versions/001_initial_schema.py`
- **Verification:** Model import and contract checks confirmed all timestamp columns have `timezone=True` and server defaults.
- **Committed in:** `49e7778` and carried into `60b4e32`
