  <action>Create bot/polling.py with:
- async def poll_and_acknowledge(bot, settings, poll_interval: float | None = None) -> None
- Engine/session initialization BEFORE the loop:
  - engine = create_async_engine(settings.DATABASE_URL, echo=False, pool_pre_ping=True)
  - session_factory = async_sessionmaker(engine, class_=AsyncSession)
- Inside try: async with session_factory() as session:
  - Query: select(MealLog).where(MealLog.processing_status == MealProcessingStatus.PENDING).order_by(MealLog.created_at.asc()).limit(1).with_for_update(skip_locked=True)
  - If meal found:
    - bot.send_message(chat_id=settings.TELEGRAM_CHAT_ID, text=format_ack_message(meal.id))
    - meal.processing_status = MealProcessingStatus.DETECTING
    - await session.commit()
- except asyncio.CancelledError: raise (critical — enables clean shutdown)
- except Exception: logger.exception("Error in poll_and_acknowledge") and continue
- await asyncio.sleep(poll_interval or settings.BOT_POLL_INTERVAL)
CRITICAL: engine and session_factory are created at function entry (before the while loop) — NOT at module import time. Engine is NOT created by the API's lifespan in this separate container.</action>
