## Interview Architecture

| Option | Description | Selected |
|--------|-------------|----------|
| Keep LLM-threaded interview | Continue using the interview model to ask, interpret, and decide readiness. | |
| Deterministic clarification UI | Reasoning emits a clarification schema; Telegram renders template questions and stores structured answers. | ✓ |
| Fully deterministic interview and finalization | Avoid LLMs for both questions and final resolution. | |

**User's choice:** Deterministic clarification UI.
**Notes:** User proposed that the reasoning model should output the clarification scheme, then deterministic templates should render MCQs/open fields. This addresses Phase 4.2 UAT failures where the LLM skipped missing answers or got stuck on repeated validation.
