# Phase 04.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| OpenRouter grouped output -> app gate | Model output is accepted only after strict grouped-schema coercion and per-group gate evaluation. | `food_groups`, candidate rankings, `trace_id`, gate state |
| Grouped meal state -> segment audit rows | One meal-level reasoning result fans out into per-segment audit snapshots without copying whole-meal candidate sets. | `MealLog.reasoning_state_json`, `MealSegment.ai_reasoning` |
| Grouped auto-confirm -> final DB write | Grouped resolutions become authoritative diary/FoodVisual writes through the existing final-write transaction. | `FinalSegmentResolution`, diary entries, visual learning rows |
| Grouped meal state -> interview session | Persisted grouped reasoning becomes DB-owned interview state for recovery and prompt rendering. | `pending_targets`, `current_prompt_payload`, `InterviewMessage` |
| Telegram reply -> grouped target advancement | User replies must advance the correct grouped target instead of falling back to raw segment identity. | `group_id`, `primary_segment_id`, answer state |
| Sample-image UAT -> trace evidence | Live verification must expose grouped reasoning and prompt continuity without introducing new grounding/package surface. | `trace_id`, grouped prompt output, Langfuse inspection steps |
