# Phase 04.2 - Security

Per-phase security contract for the LLM-threaded interview orchestration work.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| grouped reasoning state -> interview turn state | Persisted meal reasoning becomes LLM interview state and must not let stale or partial fields redefine the meal. | Meal-owned grouped reasoning, segment refs, crop/image refs, current question state |
| OpenRouter structured output -> app turn manager | Model output can advance the interview and must fail closed unless it satisfies strict schema and full-group coverage rules. | Provider response JSON, parsed turn action, confirmation items |
| config -> turn orchestration | Wrong model wiring could silently route interview traffic to an unintended model/config surface. | Interview model ids and fallback model ids |
| Telegram meal reply -> interview turn manager | Free-text user input becomes model context and must not mutate authoritative state directly. | Telegram chat text, reply metadata, bounded transcript |
| interview turn result -> finalization | `ready_to_confirm` can advance to authoritative meal write-back and must not bypass validation. | Confirmation items, approval status, group ids, segment ids |
| kickoff prompt send -> durable transcript state | The sent assistant prompt and DB-owned prompt state must stay synchronized for later reply interpretation. | Telegram message ids, `InterviewMessage`, `InterviewSession.current_prompt_payload` |
| Telegram reply metadata -> interview session resolver | Reply metadata determines which meal state may be mutated and must resolve deterministically or fail closed. | `reply_to_message.message_id`, `last_bot_message_id`, active session ids |
| meal interview routing -> `/fix` routing | The new meal-session LLM route must not capture deterministic correction sessions. | Session mode, fix correction answers, meal interview replies |
| live Telegram/Langfuse verification -> planning evidence | Manual validation must prove shipped bot and trace paths, not synthetic shortcuts. | UAT notes, Langfuse trace checks, operator checklist |
