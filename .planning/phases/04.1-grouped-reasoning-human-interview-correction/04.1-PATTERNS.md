**Top-3 coercion and defaults** (lines ~86-158):
```python
def _coerce_top_three(entries: Any) -> list[dict[str, Any]]:
    safe = list(entries or [])
    while len(safe) < 3:
        safe.append({"label": "unknown", "score": 0.0, "id": None})
    return safe[:3]

def coerce_reasoning_response(payload: dict[str, Any]) -> "ReasoningResponse":
    payload = dict(payload)
    payload["top_3"] = _coerce_top_three(payload.get("top_3"))
    return ReasoningResponse.model_validate(payload)
```

**Copy guidance**
- Keep strict schema and `extra="forbid"` in all downstream reasoning/interview payloads.
- Preserve invariant that `top_3` is always emitted as three entries.
- Centralize post-validation cleanup in a schema helper (`coerce_reasoning_response`) to keep model call-sites thin.
