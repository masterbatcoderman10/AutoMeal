## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| grouped reasoning state -> interview turn state | Persisted reasoning data becomes model input and must include all active groups without letting stale or partial fields redefine the meal state. |
| OpenRouter structured output -> app turn manager | Model output crosses into durable interview flow and must fail closed unless it matches the strict contract and full-group coverage rules. |
| config -> turn orchestration | Wrong model wiring would silently send interview traffic to an unintended model or untraced path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04.2-01 | Tampering | `app/services/interview_service.py` | mitigate | Build a single authoritative `build_interview_turn_state()` payload from meal-owned grouped reasoning, with separate `unresolved_targets` and `approval_candidates`, so the model never invents active groups or drops clear approvals. |
| T-04.2-02 | Tampering | `app/services/interview_schema.py` | mitigate | Require `turn_action`, `assistant_prompt`, and strict `confirmation_items` coverage with `additionalProperties=False` and full required keys; reject partial or extra fields before state mutation. |
| T-04.2-03 | Repudiation | `app/services/interview_turn_manager.py` | mitigate | Trace the selected interview model, bounded transcript/state payload, raw provider response, and parsed result through Langfuse so each turn remains auditable against REASON-04. |
| T-04.2-04 | Elevation of Privilege | `app/config.py` | mitigate | Add explicit `INTERVIEW_MODEL` and `INTERVIEW_FALLBACK_MODEL` settings instead of inheriting reasoning-model defaults, so the interview path cannot silently escalate to an unintended model/config surface. |
| T-04.2-SC | Tampering | package-manager surface | accept | No new packages or install tasks are allowed in this phase; the contract scaffold must ship on the existing pinned stack. |
</threat_model>
