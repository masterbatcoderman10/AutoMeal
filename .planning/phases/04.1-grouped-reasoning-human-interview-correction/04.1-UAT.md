## Deterministic Regression Gate

Run the grouped reasoning and interview regression suite first:

```bash
rtk python3.12 -m unittest \
  tests.test_reasoning_contract \
  tests.test_reasoning_flow \
  tests.test_reasoning_gate \
  tests.test_interview_flow \
  tests.test_match_flow
```

Expected result:
- All tests pass.
- `tests.test_interview_flow` proves `pending_targets` come from grouped `food_groups`.
- `tests.test_match_flow` proves the unresolved worker path sends the grouped egg-curry prompt instead of a raw segment prompt.

## Live Sample Run

Run the grouped UAT probe against the reference meal image:

```bash
rtk .venv/bin/python scripts/embed_match_smoke.py \
  --mode grouped-uat \
  --sample sample_images/IMG_4646.HEIC
```

Expected output fields:
- `meal_id`
- `food_groups`
- `unresolved_group_ids`
- `current_prompt`
- `trace_id`
- `trace_metadata.segment_crop_paths`

Expected grouped result shape:
- `food_groups` contains separate logical groups for the egg curry, chicken curry, and pita/flatbread portions.
- `unresolved_group_ids` includes only the group that still needs clarification.
- `current_prompt` is:

`I can see the egg curry, but I can't tell which vegetable is in it. What should I call it? For example: egg curry with bottle gourd, egg curry with zucchini, or the name you normally use.`
