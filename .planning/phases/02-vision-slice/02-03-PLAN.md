<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| Partial invalid model output becomes partially accepted and corrupts downstream crops | HIGH | Reject the entire response when any box is invalid and rerun once with the stronger model |
| Same food item is double-counted due to overlapping regions | MEDIUM | Apply IoU > 0.5 dedupe before persistence and before message formatting |
| Retry logic loops indefinitely or silently reuses the same weak prompt | MEDIUM | Hard-cap at one retry and require the explicit retry model ID in code and tests |
| Weak labels clutter the result sentence with repeated or uncertain noise | LOW | Collapse duplicate names and localize hedging to weak items only |
</threat_model>
