## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| grouped reasoning state -> interview turn state | Persisted reasoning data becomes model input and must include all active groups without letting stale or partial fields redefine the meal state. |
| OpenRouter structured output -> app turn manager | Model output crosses into durable interview flow and must fail closed unless it matches the strict contract and full-group coverage rules. |
| config -> turn orchestration | Wrong model wiring would silently send interview traffic to an unintended model or untraced path. |

## STRIDE Threat Register

| Threat ID | Category | Component | ASVS L1 Ref | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|----------|-------------|-----------------|
| T-04.2-01 | Tampering | `app/services/interview_service.py` | V5 Input Validation | High | mitigate | Build a single authoritative `build_interview_turn_state()` payload from meal-owned grouped reasoning, with separate `unresolved_targets` and `approval_candidates`, so the model never invents active groups or drops clear approvals. |
| T-04.2-02 | Tampering | `app/services/interview_schema.py` | V5 Input Validation | High | mitigate | Mirror the strict-schema pattern from `app/services/reasoning_schema.py`, require `turn_action`, `assistant_prompt`, `confirmation_items[*].approval_status`, and full-group coverage with `additionalProperties=False`, allow at most one repair retry, then reject partial or contradictory payloads before any confirmation-state mutation. |
| T-04.2-03 | Repudiation | `app/services/interview_turn_manager.py` | V3 Session Management | Medium | mitigate | Mirror the retry/repair/trace pattern from `app/services/reasoning_service.py` and wrap the existing `app/services/llm_client.py` transport with `app/services/tracing_service.py` so the selected interview model, bounded transcript/state payload, raw provider response, repair attempt if used, and parsed result remain auditable against REASON-04. |
| T-04.2-04 | Elevation of Privilege | `app/config.py` | V4 Access Control | Medium | mitigate | Add explicit `INTERVIEW_MODEL` and `INTERVIEW_FALLBACK_MODEL` settings instead of inheriting reasoning-model defaults, so the interview path cannot silently escalate to an unintended model/config surface. |
| T-04.2-SC | Tampering | package-manager surface | V5 Input Validation | Low | accept | No new packages or install tasks are allowed in this phase; the contract scaffold must ship on the existing pinned stack. |

Security gate: per `.planning/config.json` (`security_asvs_level=1`, `security_block_on=high`), any unmitigated High finding blocks execution and downstream handoff until fixed.
</threat_model>
