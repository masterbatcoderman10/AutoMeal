## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| crop file -> OpenRouter embeddings API | Untrusted meal-segment image data leaves the local host and must be minimal, validated, and retried safely. |
| OpenRouter response -> application vector storage | Remote JSON must not be trusted until vector shape and dimensionality are checked. |
| sample seed helper -> local database | Demo seed material may populate `FoodVisuals`, but invalid or malformed seed writes must not poison later similarity logic. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | `scripts/embed_match_smoke.py` | mitigate | Send only saved crop inputs for calibration and seed paths per D-06, not whole-meal images once crops exist. |
| T-03-02 | Tampering | `app/services/embedding_service.py` | mitigate | Validate response presence, vector length `== 1536`, and task-type call site before assigning any embedding to ORM rows. |
| T-03-03 | Denial of Service | `app/services/llm_client.py` | mitigate | Bound retries to transport and 429/5xx failures with explicit timeout and no retry on parse/validation errors. |
| T-03-04 | Repudiation | `scripts/embed_match_smoke.py` | mitigate | Print explicit calibration verdicts and sample paths so Wave 0 evidence is reproducible. |
| T-03-SC | Tampering | Python dependency/runtime surface | accept | No new packages are installed in this plan; rely on the existing locked stack from Phase 1. |
</threat_model>
