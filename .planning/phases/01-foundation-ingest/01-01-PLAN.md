<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| Shared secret exposed in docker-compose logs | HIGH | Never inline secrets in compose; use env_file or `${VAR}` substitution |
| Postgres password hardcoded | HIGH | Always via `${POSTGRES_PASSWORD}` env var from .env |
| API port exposed to host network | MEDIUM | Bind to 127.0.0.1:8000, not 0.0.0.0:8000 for host port mapping |
| Firecrawl simple image has no auth | MEDIUM | Internal-only network (no host port); single-user stack; fine for v1 |
| .env committed to git | HIGH | .env in .gitignore; only .env.example committed |
</threat_model>
