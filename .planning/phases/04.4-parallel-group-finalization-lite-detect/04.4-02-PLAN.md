| Boundary | Description |

| concurrent group fan-out -> meal-scoped transaction | Parallel metadata composition feeds one shared authoritative commit boundary here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04.4-04 | Tampering | `app/services/interview_service.py` input builder | mitigate | Build one finalizer input per group with only that group's reasoning, candidates, clarification answers, and segment refs per D-01/D-03. |
| T-04.4-05 | Denial of Service | `app/services/interview_service.py` fan-out | mitigate | Use `asyncio.Semaphore` plus explicit result envelopes so one failed/slow group does not cancel siblings; avoid TaskGroup-style first-failure cancellation per D-02/D-14. |
| T-04.4-06 | Tampering | finalizer JSON parser/mapping | mitigate | Parse strict schema only, fail closed on malformed JSON, and record explicit failure metadata before degraded fallback per D-05/D-14. |
