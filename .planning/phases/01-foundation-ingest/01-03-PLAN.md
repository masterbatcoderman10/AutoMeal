<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| Missing/wrong shared secret → unauthorized access | HIGH | Header X-Ingest-Secret compared against Settings.INGEST_SECRET, 401 on mismatch (INGEST-02) |
| Malicious file upload (non-image) | MEDIUM | Content-type validation — reject non-image/* with 400 |
| Oversized HEIC causing OOM | MEDIUM | iOS photos are < 10MB typically; Pillow handles HEIC in memory. Add 20MB file size guard in Phase 2+ |
| Hash collision enabling dedup bypass | LOW | SHA-256 collision probability is ~1/2^128 — acceptable for single-user dedup |
| Path traversal via crafted filename | MEDIUM | Never use client filename — generate UUID server-side (D-06) |
| Duplicate meal processing on rapid resubmit | LOW | Dedup query uses 60-second window on image_hash; returns existing MealLog (INGEST-05) |
</threat_model>
